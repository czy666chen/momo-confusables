# 阶段五：本地质量验收与发布候选

2026-09-22。用户确认采用误报率 ≤10%、漏报率 ≤10%、1,000 词自动发现 ≤5 秒、全快照 ×20 查询手动查找 ≤3 秒的本机目标，并明确“先交付 localhost”。本次完成本地实现、自动化验证和可回滚产物；**人工标签核验、Cloudflare 线上实测和正式发布未完成**。

## 评测与阈值

新增 160 对样例，调参 / 验收各 80 对，各 40 正例和 40 负例；两个分区不共享单词。涵盖同音、近音、多读音、短词、长词、拼写陷阱和无关词。只在调参集上选择阈值，验收集不参与选择。来源与方法见 `data/pronunciation-evaluation/README.md`，逐条读音与待核验栏见 `docs/pronunciation-human-review.md`，机器结果见 `docs/pronunciation-evaluation.json`。

当前标签均由 AI 起草，未经过人工核验，以下数字只反映草案标签，不是实际用户准确率，也不是正式发布通过凭据。

| 固定阈值 0.65 | 误报 / 负例 | 漏报 / 正例 |
|---|---:|---:|
| 调参集 | 0/40（0%） | 1/40（2.5%） |
| 验收集 | 3/40（7.5%） | 1/40（2.5%） |

保留原有 0.65 阈值，统一 UI 与算法的常量。评分版本仍为 `phoneme-unit-edit-v1`；独立新增阈值策略版本 `phoneme-threshold-v1`，不改变音素资源版本，因此阶段四私人预测文件继续兼容。自动发现仍允许用户调整共同的拼写 / 发音阈值，不改变已有拼写排序或换序语义。

验收集中 `seize/size`（0.667）、`leopard/shepherd`（0.800）、`island/iceland`（0.833）被草案标为负例，但实际上存在近音标签争议，须优先人工复核；`angle/anger`（0.600）漏报。没有依据这些结果改标、改阈值或清除失败样例。若人工复核后需要调参，应重新建立独立验收集。

按最大音素长度 ≤3 与 >3 分组的调参分析，短词 0.50、长词 0.65 可在小样本调参集上消除错误。但短词样本仅 42 对，降低阈值会放宽两音素词的匹配，缺少人工依据，本次不加入长度规则。暂不增加音系特征权重与重音惩罚：当前错误首先涉及标签分歧，且 `personal/personnel`、`desert/dessert` 等本就希望召回；引入重音扣分可能伤害这些正例。没有进行加权方案准确率宣传。基础音素与重音仍分开保存并可查看。

## 召回与功能回归

保留全量音素比较，不引入索引。319 个公开词组成 50,721 个词对，以独立完整矩阵编辑距离作为基线，分别检查 0、0.65、0.8、1 阈值：集合完全相等，无额外漏召回；倒序输入结果相同。手动入口也逐项对照独立基线。这里只证明实现与穷举评分一致，不代表对人工“相似”标签的召回率为 100%。

单元测试检查双入口七组合的 OR 并集、去重、合并标签、基础结果相对顺序和稳定排序。浏览器回归覆盖双入口七组合、同步选择、鼠标/键盘/触屏最后一项约束、双入口分页重置、空结果、词表更新、迟到请求、旧词典版本重读、网络失败降级/恢复、私人预测版本失效和移除。关闭发音不请求词典。

修复刷新失败时旧快照仍显示“本次已核对”的问题：刷新一开始撤销旧快照的完整标记，失败保留已取回记录并显示部分范围。覆盖请求尚未返回记录就失败，以及返回部分记录后最终核对中断的场景。

## 真实规模性能

私有快照为 7,140 / 7,154 条，未完整覆盖；薄弱词 277 个。基准只保存数量与耗时，不将具体私人词项写入报告或公共目录。

Node 26.2.0，Windows，i5-13500H；每场景 3 次，采用最大耗时判断通过。Node 基准合并已有 84 个预测读音，浏览器基准仅词典读音，所以 1,000 词结果分别为 451 和 450 对，并非算法不一致。

| 实际 277 薄弱词，三类型 | 38,226 | 72–87ms | 367–543ms | ≤5,000ms |

Node 进程累计 CPU 时间分别为 63–171ms、1,063–1,125ms、297–344ms，可因线程与测量粒度超过墙钟时间，**不是 Cloudflare CPU**。浏览器基准含 Worker 创建、词典读取/解析与消息传输；首轮冷加载，随后允许 HTTP 缓存，每轮新建 Worker。主线程 10ms 心跳观察到的最大间隔 28ms，仅作为本机响应性诊断。浏览器为 Chromium 153.0.8010.12，网络为本机回环，不代表移动端或广域网首次加载。

公共词典 5,487,527 字节，gzip 1,085,365 字节。旧 `cmudict-74790861.json` 与现用 `cmudict-74790861-v2.json` 都保留在公共资源中，版本化路径继续使用 immutable 缓存。没有覆盖旧 immutable 内容。

原始数值见 `docs/pronunciation-performance.json`、`docs/pronunciation-browser-performance.json`。Cloudflare 的在线请求量、CPU、账户共享预算和费用**未测量**；不能填写为 0。现有配置仅 `/api/*`、`/dictionary/*` 先执行 Worker，`/pronunciation/*` 是静态资源；线上仍需核对实际路由与账户数据。

### 本地连接故障跟进

首次交付只验证了页面及未登录会话响应，未验证墨墨出站链路。用户反馈连接失败后，复现 `/api/connect` 返回 `502 墨墨接口连接失败`；沙箱内直连墨墨报 `connect EACCES`，沙箱外无凭证请求正常返回 401。根因为本地 Worker 运行环境禁止出站连接。已在具备网络权限的环境重启本机 8787 服务，并通过 `node scripts/check-local-api.mjs` 验证完整的本地代理 → Worker → 墨墨链路、认证会话和真实学习记录计数。该检查仅读取计数并清理自身会话，不输出凭证，不修改云词本。以后本地交付应包含此项冒烟检查，不能仅以页面 200 判断接口可用。
