# 发音评测集 v1

`pairs.tsv` 是 160 对公开英语词的 AI 起草标签，**全部待人工核验**，不含私人词表。调参 / 验收各 80 对，各含 40 个预期正例、40 个预期负例；两分区不共享单词。类别包括同音、多读音、短词近音、长词近音、拼写陷阱及无关词。

标签在首次评分前写入；首次评分后的验收标签保持冻结，不因结果不理想而改标。`seize/size`、`leopard/shepherd`、`island/iceland` 的“负例”标签与近音标准可能存在分歧，必须优先由人工检查。不能把自动分数当作标签真值；当前统计只是草案标签上的诊断，不是经核验准确率。

运行 `npm run evaluate:pronunciation`：仅在调参集上枚举 0.50～1.00（步长 0.05），最小化误报率加漏报率；并列时优先最接近现有 0.65 的值。固定选中阈值后再评分验收集。误报率分母为负例数，漏报率分母为正例数。

结果写入 `docs/pronunciation-evaluation.json`；首次生成 `docs/pronunciation-human-review.md`，后续运行不会覆盖人工批注。核验者需记录姓名、日期、判定和分歧；如果依据当前验收集改标签或调算法，应另建未参与分析的新验收集，不能复用当前验收集宣称独立达标。现有评测不测任意 G2P 预测的准确率，也不评估英式读音或语境消歧。
